# 企銀資料整理卡

中小企業月營收 Excel 標準化的可操作展示版。對應臺灣企銀提案中的單一作業情境，不涉及徵信、信用評分或授信建議。

## 使用

開啟 `index.html`，點「載入兩份虛構範例」或匯入自己的 `.xlsx`、`.xls`、`.csv`。逐一核對工作表的月份、營收和單位欄位，按「確認此工作表」。檢視缺月、重複及單位不明等項目後，下載含「標準化月營收」與「缺漏與待確認」工作表的 Excel。

GitHub Pages：在 repository Settings → Pages 選擇 **Deploy from a branch**、`main`、`/(root)`，儲存後即可透過 Pages 網址使用。首次開啟需連線載入 SheetJS 解析套件。

## 資料與邊界

- 資料只在本次瀏覽器工作階段處理；不傳送至自建伺服器，不建立資料庫。重新整理頁面會清除資料。Excel 解析套件由 cdnjs 提供，需連線載入程式庫。
- 欄名候選目前使用本機語意規則及信心提示，**尚未整合提案規劃的瀏覽器端輕量 AI 模型**。日期解析、金額換算和缺漏檢查採固定規則，可由專員核對。
- 匯入上限為 5 份檔案，每份 5 MB。原型以「一列代表一個月份或一筆營收」的工作表為主；合併儲存格、跨欄表頭、混合幣別及複雜公式需人工檢查。
- 重複月份保留原始多筆資料，不自動加總；單位不明時不換算金額。缺月僅在單一工作表可解析的最早與最晚月份之間檢查。
- 所有示範企業與數字均屬虛構，不能用於實際授信決策。正式試辦須另行完成資料授權與資安審查。
